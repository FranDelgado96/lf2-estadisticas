# Estadísticas Liga Femenina 2 · 2026/27

Web pública con clasificación, calendario, jornadas, resultados, actas y estadísticas de jugadoras de Liga Femenina 2 de baloncesto.

- `index.html`: la web (sin dependencias ni compilación; Vercel la sirve tal cual).
- `data/bundle.json`: datos; se regeneran automáticamente con `tools/lf2_tool.py`.
- `actas/`: PDF con la estadística oficial FEB de cada partido.

Fuente de los datos: www.feb.es
